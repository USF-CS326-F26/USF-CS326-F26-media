# CS 326 media

Video files for the CS 326 (Operating Systems, USF, Fall 2026) course site,
https://cs326-f26.cs.usfca.edu/. This repository is its own GitHub Pages site,
served under the course domain at https://cs326-f26.cs.usfca.edu/USF-CS326-F26-media/,
so the main site stays under Pages' 1 GB limit.

Only the MP4s live here, in `videos/`. Each video's player page, captions and
links are on the main site (USF-CS326-F26/USF-CS326-F26.github.io, `docs/videos/`),
and its CONTRIBUTING.md says how a video is encoded and added.
